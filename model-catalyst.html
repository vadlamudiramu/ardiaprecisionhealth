Catalyst

The governed answer to "invent a drug while I grab coffee"

Three stages — assess the molecule, screen it for measured off-target liabilities, shortlist trials a patient could be screened for. What makes it Ardia's is that every stage is answerable for its own evidence, and a stage with nothing to stand on says so instead of producing something plausible.

Four things Catalyst does not do

The industry demo reel promises a machine that invents a drug, clears it, and fills the trial while you fetch coffee. Catalyst is the version of that idea which survives someone reading the code.

⚠︎ The honest boundary

It does not design or propose molecules. There is no generative chemistry here. Catalyst scores a compound you name, using descriptors that were supplied or fetched from PubChem. It will not even parse a SMILES string into descriptors — that needs a fitted cheminformatics model, and an approximation would be confidently wrong exactly where it matters.

It does not predict binding, and it does not predict off-target activity. Stage 2 retrieves what has already been measured and published in ChEMBL. Where nothing has been measured, it says no data — which is the normal state for most compound/target pairs, and is not a clean bill of health.

It does not determine eligibility or recruit anyone. Stage 3 returns a shortlist for a human screener, with the reasoning shown for every criterion. Real eligibility lives in free-text inclusion/exclusion prose — labs, performance status, washout, comorbidity — which Catalyst does not read and never pretends to.

It does not let the language model do the chemistry. The deterministic kernel runs first; the model is handed the computed result and told to explain it. Ordering is the entire guarantee: the numbers exist before the model is invoked, so it is narrating a computation rather than producing one.

What it does

Three stages, each answerable for its evidence

Every stage returns one of four statuses — ok, no_data, blocked or skipped. There is no fifth option where a stage quietly produces output it has no evidence for.

01

Developability — published filters, plain arithmetic

Five peer-reviewed filters applied to real descriptors: Lipinski's Rule of Five (1997), Veber (2002), Egan (2000), Ghose (1999) and the fragment-oriented Rule of Three (Congreve, 2003). A filter whose descriptors are missing returns not_evaluated — never a pass, because treating "unknown" as "fine" is the way these filters are most often misused. Ghose reports its molar-refractivity and atom-count criteria as unevaluated rather than assuming they passed.

Ligand efficiency (Hopkins) and lipophilic efficiency (Leeson) appear only when the caller supplies a measured affinity together with its source. An affinity with no attribution is refused outright — it cannot be told apart from a guess.

02

Off-target — measured liabilities, retrieved not inferred

The panel is the in vitro pharmacological profile proposed by Bowes et al. (2012), plus hERG, which regulators require in the ICH S7B core battery — 37 targets spanning cardiovascular, CNS, transporter, enzyme and nuclear-receptor liabilities. Measured activities are pulled from ChEMBL and classified by pChEMBL: at or below 1 µM flags, 1–10 µM is weak, weaker than 10 µM does not flag.

Targets are identified by HGNC gene symbol only. ChEMBL accessions are resolved at run time and never hardcoded, so this model cannot ship a stale or invented ID. Where a selectivity margin can be computed against a measured primary potency, the conventional two-log expectation is applied — and labelled as the rule of thumb it is.

03

Trial matching — candidates for a human, never an enrolment

A de-identified profile is compared against the structured fields of registered studies: recruiting status, condition overlap, age window, sex, biomarker mention and site location. Each study comes back with a per-criterion trace where undetermined is a first-class outcome, not a rounding error.

Age is a band, never a date of birth, and bands top out at 90+ to match HIPAA Safe Harbor. That is also why a band which only partly overlaps a study's window resolves to undetermined rather than a guess — the precision was given up deliberately, and pretending to have it back would defeat the point.

How it is governed

The controls are code, not copy

Catalyst reuses the same enforced boundary every other Ardia model passes through — Sentinel de-identification, the HIPAA technical-safeguards guard, and a PHI-free audit trail — plus two constraints specific to running a discovery pipeline near patient data.

01 · DE-IDENTIFY

Before anything is compared

The trial stage runs the HIPAA guard's preflight over the profile before any matching happens, so identifiers stuffed into a condition field are redacted or the input is refused.

02 · CONTAIN

Profile text never egresses

Only the caller's explicit condition: directive reaches ClinicalTrials.gov. Sentinel redacts structured identifiers, but its name handling is roster-based by design — so a name typed into a condition field would survive scrubbing. Keeping profile text in-process closes that gap structurally rather than hoping a regex catches it.

03 · AUDIT

Every stage, metadata only

Each stage writes a PHI-free audit event — stage, status, counts, and the categories de-identified. Never the content. String metadata is length-capped so content cannot be logged by mistake.

04 · FAIL CLOSED

No guardrail, no run

If the de-identification guardrail cannot be imported, the trial stage is blocked rather than run unprotected. If the kernel itself is unavailable, the Studio endpoint refuses the question instead of letting the model improvise chemistry.

How to run it

Directives, not prose

Catalyst reads explicit key: value lines and nothing else. A model asked to infer "which molecule did they mean" will always produce an answer — including when the text names no molecule at all, and a confidently wrong compound poisons all three stages.

The directive block

One per line. compound: and condition: are the ones that matter.
compound: imatinib
condition: chronic myeloid leukemia
affinity: 8.5
affinity_source: ChEMBL Ki, assay ID
age: 45-60
sex: female
region: Texas
biomarkers: BCR-ABL, T315I
Anything Catalyst ignores is reported back — a bad age format, an affinity with no source, a missing compound. It never silently drops an input.

Each refusal is a unit test, not a guideline.

What is measured, and what is not

◐ Deterministic core: verified. Narration: unmeasured.

The rule engine is deterministic and unit-tested, in the same class as Meridian's PAMA math — same input, same output, no model in the loop, 52 offline tests covering the filters, the panel logic, the matcher, the source parsers and the governance path. That part is verifiable by reading the tests.

The narration layer has no published accuracy. The prose Catalyst writes about a run comes from a frontier model under guardrails, and like every other Ardia persona it carries no measured accuracy figure yet. It is constrained to the computed block and instructed to report empty stages plainly — but "constrained" is a control, not a benchmark.

Retrieval is best-effort. PubChem, ChEMBL and ClinicalTrials.gov are public services with no key and no SLA. When one is slow or down, the affected stage degrades to no_data — it never raises, and it never causes a fabricated result. A run that reports nothing is doing its job.

This is research tooling, not clinical care, and it is not a substitute for regulated safety pharmacology, a qualified medicinal chemist, or a clinical screener. Ardia is pre-revenue and seed-stage; no part of Catalyst has been used on real patient data.
